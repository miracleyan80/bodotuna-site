ドリームアイランド ～理想のテーマパークを作ろう～（ブラウザ版）
==============================================================

■ 遊び方
  index.html をダブルクリックするだけで遊べます（ネット接続不要）。
  ※ Chrome / Edge / Firefox など、最近のブラウザで動作します。

■ ゲームの流れ
  ① 島を選ぶ（5つの島から1つ選択）
  ② スポンサーカードを1枚引く（効果が開発中ずっと適用）
  ③ アトラクションを選び、光ったマスをクリックして設置
     ・最初は港まわりの赤枠3マスのみ
     ・以降は設置済みアトラクションに隣接したマスに設置
     ・ミニ施設（黄色）は設置済みマスに重ねて設置も可能
     ・置いたアトラクションは、左上の「×」ボタンで取り消し（コスト返却）
     ・マスにカーソルを合わせると、その地形の効果が表示されます
  ④ コスト(50)を使い切る／置けるマスが無くなったら「開発完了・評価する」
  ⑤ エンタメ値×ネイチャー値の組み合わせでパークの評価が決まります

■ 地形の効果（建設コスト −1）
  ビーチ → 飲食店 / 森 → アウトドア / 山 → 乗り物 / 川 → 飲食店 / 平地 → ショー
  スポンサー効果（コスト2以上の対象に −1）と重複可能（合計 最大 −2）

■ ルール・データの出典（すべて「印刷」フォルダの最終版＝決定稿）
  ・島マップ.pdf（5つの島）
  ・アトラクション1.pdf／アトラクション2.pdf／アトラクション3.pdf
    （全76種のアトラクション絵柄は、この3枚からのみ切り出して使用。他フォルダの古い絵は不使用）
  ・スポンサーカード.pdf（4社）
  ・パーク分類表.pdf（評価マトリクス：0-30/31-40/41-50/51-60/61〜）
  ・遊び方.pdf

■ ファイル構成
  index.html … ゲーム本体（HTML/CSS/JS）
  data.js     … ゲームデータ（アトラクション・5島の地形・スポンサー・評価表）
  assets/islands     … 5つの島マップ画像
  assets/chips_print … アトラクションの絵柄（アトラクション1〜3.pdfより切り出し）
  assets/sponsors    … スポンサーカード画像
  assets/specials    … 海賊砦・お城・プロジェクションマッピングの2×2盤面タイル（アトラクション3.pdfより）

  ※ 数値や地形を調整したい場合は data.js を編集できます。
